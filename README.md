# 우리 후쿠오카 여행 (2026.11.29 – 12.04)

둘이 쓰는 후쿠오카·벳푸 5박 6일 여행 앱. 휴대폰 화면 기준으로 만든 한 페이지짜리 웹앱이다.

**바로 열기:** https://dongnam4425.github.io/fk-trip-2611/

## 기능

- **일정**: 날짜를 좌우로 넘기며 보는 하루 단위 일정, 장소마다 대표 사진과 구글맵 링크, 일정마다 메모
- **Claude Code로 일정 넣기**: Claude Code에 "12/1엔 유후인 갔다가 벳푸" 처럼 말하면 실제 장소를 찾아 `src/trip-data.js`에 넣고 배포한다. 휴대폰 앱은 다음에 열 때 새 일정을 자동으로 합친다 (내 메모·추가 일정·지출은 유지)
- **여행 비서 (+ 버튼)**: "12월 1일 오후 3시 캐널시티 구경"처럼 날짜·시간·할 일을 말하거나 쓰면 바로 일정에 등록 (API 키 없음)
- **예산**: 둘이 쓴 돈, 사람별 금액, 공용/개인 구분, 반반 정산 계산
- **영수증**: 사진을 올리면 합계·가게·날짜를 읽어 지출 칸을 채움 (Tesseract.js, 브라우저 안에서 처리)
- **정할 것**: 남은 결정 사항 체크리스트, 이름 설정, 백업
- **예산 → 준비물**: 여행 전 준비물 체크리스트(여권·Visit Japan Web·스이카·엔화 등). 체크 상태는 휴대폰에 저장되고, 직접 항목을 추가하거나 뺄 수 있다

## 데이터와 키

- 일정·지출·메모·준비물 체크는 각자 브라우저(localStorage)에 저장된다. 둘이 맞출 때는 예산 → 내역·정산의 "내 기록 보내기 / 받은 기록 합치기"를 쓴다.
- Google 지도 API 키(선택, 장소 사진용)는 브라우저에만 저장되며 이 저장소에는 들어 있지 않다.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 배포되는 완성본 (GitHub Pages가 이 파일을 연다) |
| `src/template.html` | 화면·기능 원본 |
| `src/trip-data.js` | 기본 일정·예산 데이터 |
| `src/build.ps1` | 원본을 합쳐 `index.html`을 만드는 스크립트 (PowerShell, 추가 설치 없음) |
| `CLAUDE.md` | Claude Code에게 말로 일정을 넣는 작업 방식 |
