# 우리 후쿠오카 여행 (2026.11.29 – 12.04)

둘이 쓰는 후쿠오카·벳푸 5박 6일 여행 앱. 휴대폰 화면 기준으로 만든 한 페이지짜리 웹앱이다.

**바로 열기:** https://dongnam4425.github.io/fk-trip-2611/

## 기능

- **일정**: 날짜를 좌우로 넘기며 보는 하루 단위 일정, 장소마다 대표 사진과 구글맵 링크, 일정마다 메모
- **여행 비서 (+ 버튼)**: 대화하듯 말하면 Claude가 웹에서 실제 식당·관광지를 찾아 구글맵과 함께 일정에 등록 (Claude API 키 필요). 키 없이도 "12월 1일 오후 3시 캐널시티 구경" 같은 문장은 바로 등록
- **예산**: 둘이 쓴 돈, 사람별 금액, 공용/개인 구분, 반반 정산 계산
- **영수증**: 사진을 올리면 합계·가게·날짜를 읽어 지출 칸을 채움 (Tesseract.js, 브라우저 안에서 처리)
- **정할 것**: 남은 결정 사항 체크리스트, 이름·API 키 설정, 백업

## 데이터와 키

- 일정·지출·메모는 각자 브라우저(localStorage)에 저장된다. 둘이 맞출 때는 예산 → 내역·정산의 "내 기록 보내기 / 받은 기록 합치기"를 쓴다.
- Claude API 키, Google 지도 API 키는 브라우저에만 저장되며 이 저장소에는 들어 있지 않다.

## 파일

| 파일 | 내용 |
